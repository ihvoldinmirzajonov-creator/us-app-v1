# Us App — Monorepo (Figma, Expo starter, Firebase scaffold)

This repository contains three main parts to kickstart the Us app project:

- /figma — Figma starter pack: design tokens, SVG logo, component specs, frames, README
- /expo — Expo + TypeScript starter app with navigation, design tokens, HeartPhoto component and Home screen stub
- /firebase — Firestore security rules, Storage rules, Cloud Functions stubs, and seed script

Each subfolder contains README and instructions for setup.
